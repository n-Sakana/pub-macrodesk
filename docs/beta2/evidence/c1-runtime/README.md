1120×840 に対応）で撮った画面。診断画面の「この診断が前提にしている環境」を
開いた状態。

| 画像 | 何を確かめたか |
| --- | --- |
| `runtime-facts-known.png` | 端末から読めた値（OS x64 / プロセス x64 / Office 16.0.20228.20124 x86）が、想定動作環境とは別の見出し「この端末で確認できた実行環境」の下に並ぶこと。`expectedRuntime` を宣言した所有者に対してだけ「期待 … / 一致」「期待 … / 不一致」が付き、不一致の行だけが赤くなること。 |

どちらの画像でも、直下の一文が「ブックの属性ではありません。配布先の端末では
別の値になります。」であること、文字切れ・重なり・横はみ出し・二重スクロールが
無いことを目視で確認した。行の折り返しは語単位で、1 文字幅へ潰れていない。

自動計測（`testdata\__audit.js` の `measure`）でも、この 2 状態で
横方向のはみ出し・過大なボタン・崩れた行の検出は 0 件。

数値そのものは `tests\test-host-runtime.ps1` が実レジストリへ read-only で
当てて確認している。Excel も COM も起動していない。
