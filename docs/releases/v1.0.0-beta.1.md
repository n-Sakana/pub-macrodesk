## このツールでできること

Excel ブック（`.xlsm` / `.xlam` / `.xlsb` / `.xls`）の VBA を、VBE を開かずに
見て・調べて・直すためのツールです。どこをどう直すかの判断はチャット AI が行い、
MacroStudio は判断材料を運び、返ってきた結果を安全にブックへ書き戻す配管に
徹します。

**元のブックは変更しません。** 改修結果は必ず別名の新しいブックとして、
専用フォルダに作られます。

- 作業を選び、ブックを読み込み、依頼文とコード全文ファイルを作る
- AI の返答を 1 回の操作で取り込み、依頼番号で「今回の依頼への返答か」を検査する
- 取り込んだ変更を差分で確認し、改修済みブックと差分レポート HTML を作る
- コードが長いときは「モジュール単位出力」で 1 モジュールずつ受け取る
- 依頼のひな形 6 種を同梱。`presets\*.md` を差し替えれば目的を変えられる

## 動作要件

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11（64 ビット） |
| PowerShell | Windows PowerShell 5.1（OS 標準） |
| .NET Framework | 4.7.2 以降（OS 標準） |
| WebView2 ランタイム | 必要（Windows 11 は標準搭載。無い場合は起動時に案内） |
| Microsoft Excel | ツール自体には不要。改修後の動作確認時に使用 |
| ネットワーク | ツール自体は完全ローカル動作 |

## 既知の制約

- 新しく追加できるのは標準モジュールだけです。モジュールの削除・名前変更、
  新しいクラスや UserForm の追加には対応していません。
- ファイル全体が暗号化された（開くときにパスワードを求められる）ブックは
  読み込めません。
- 署名付き VBA プロジェクトは、コードを書き換えると署名が無効になります。
- 改修箇所の検出・提案や、AI の回答内容の保証は行いません。
- `.xlsm` は抽出・書き戻し・Excel での再オープンまで確認済みです。
  `.xlam` / `.xlsb`、パスワード保護された VBA プロジェクトは実ファイルでの
  検証が未完了です。
- ベータ版です。改修後のブックは必ず Excel で開き、動作を確認してください。
